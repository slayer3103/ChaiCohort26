# Mintlify Landing Page Clone

A front-end recreation of selected sections from the official Mintlify website.

The objective of this project was to replicate the layout, typography, spacing, and visual hierarchy using only HTML and CSS.

---

## 🚀 Tech Stack

- HTML5  
- CSS3  
- Google Fonts (Inter)  
- Pure CSS animations  

No frameworks or JavaScript libraries were used.

---

## 📌 Sections Included

- Header / Navigation  
- Hero Section  
- Partners Section  
- Features Section  
- Enterprise Section  
- Customer Section  
- Call-to-Action  
- Footer  

---

## ✨ Highlights

- Fixed transparent header with scroll animation  
- Responsive grid-based layouts  
- Clean typography and structured spacing  
- Organized and reusable CSS
